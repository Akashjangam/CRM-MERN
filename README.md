# CRM - Customer Relationship Management System

A full-stack CRM application built using the MERN stack.

## Features

### Backend
- User registration
- User login
- JWT authentication
- Password hashing using bcrypt
- Customer CRUD operations
- Case CRUD operations
- MongoDB database integration
- Input validation
- Error handling
- REST API development

### Frontend
- User registration and login
- Customer dashboard
- Add customers
- View customers
- Update customers
- Delete customers
- Responsive user interface
- Backend API integration

## Technologies Used

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- dotenv
- cors

### Frontend
- React.js
- JavaScript
- Tailwind CSS
- Axios
- React Router DOM
